# Task 1 DVC evidence

Verified on 13 October 2026 with DVC 3.50.1 and Python 3.12.
The implementation follows module-03-dvc-gx and the supplied project rubric.

The `prepare` stage declares `scripts/load_data.py`, split size, seed, data
location, dataset ID, and immutable dataset revision. Its outputs are
`data/train.csv` and `data/test.csv`. The `clean` stage declares
`scripts/clean_data.py`, `data/raw_stream.csv`, and the cleaning parameters;
its output is `data/stream.csv`. DVC is initialized inside `starter/`.

  444 cleaned posts from 500 raw posts.
- All texts are nonempty; both labelled splits contain the three expected labels.
- An unchanged rerun skipped both stages.
- Forced reproduction regenerated byte-identical outputs.
- Changing `clean.min_words` from 10 to 11 in a dry run invalidated only clean;
